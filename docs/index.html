Executive summary

This repository is an evidence-first attempt at the DOE GEMS Prize (DrivenData competition 306). The task is to predict, for each 100 m cell, the probability that a geothermal-relevant fault is present, and submit that as a GeoTIFF. The score is a distance-weighted Tversky index (DTI).

The error "Predicted values must be in range [0, 1]"

The portal rejects a file when any finite cell is outside [0, 1]. Three things typically cause it:

  • Negative or >1 values from a model that was not clipped or passed through a probability.
  • A nodata sentinel such as -3.4028234663852886e+38 left inside the footprint. The owner's site attributes the error to this (claim, IR-06). It could not be checked here because the training file is absent.
  • NaN or a wrong grid (for example a different transform or size).

Fix: clip to [0, 1], write NaN outside the footprint, then run the validator. The validator is in src/gems/submission.py and rejects all three cases.

Unique name and comment

Name — must be unique to you. Use a name that carries the method and a unique tag, for example gems-56-corr-k25-2026-10-09. Do not reuse a name seen in another repository (see the duplicate audit).
Comment — short, plain, and true. Example: clustering with k=25. Describe the method in one line. The form's character limit is not verified here; keep the comment well under 140 characters.

Rules: can I download and submit the TIF?

Short answer: Yes, for a TIF you generate yourself, from data you are entitled to use — no clause of the official rules (all 7 chunks read) prohibits it. No, for any TIF that someone else produced (for example a sibling repository's file): it is third-party content, which our own rule forbids and which A.5 excludes unless disclosed and licensed.

  • A.4 (public elements): "The elements of the submission that are designated as public will become publicly available… these elements must not include trade secrets or business-sensitive, proprietary, or otherwise confidential information." Public elements are licensed to DOE and may be posted.
  • A.5(1) (original work): the submission must be "an original work by the competitor" and must not include third-party content "unless… disclosed by the competitor in the submission and… the competitor has acquired the necessary rights".
  • §3.2 (generative AI): any generative-AI use must be disclosed in the narrative.
  • Not covered by the rules: the terms of the training data itself. The data page is login-gated and its terms were not read here. Check them before downloading the training files.

How numbers are labelled

  • HOLDOUT-DTI — a score on our spatially blocked holdout, with evaluator version, number of withheld positives and a 95% CI. None exists yet.
  • ORGANIZER-CONFIRMED — copied from an organiser receipt. None exists yet.
  • CLAIM — reported by someone else and not verified here. Every leaderboard figure is in this class.
  • PROXY — a measurement on stand-in data. Never a score.
