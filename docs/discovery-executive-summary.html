3. What you are submitting

A single-band float32 GeoTIFF on the official grid (EPSG:32611, 100 m, 3292×3730, same transform as sample_submission.tif): 6,504 unit dots on the evidence-defined traces of 28 catalogue records whose DEM-scarp crest sits consistently > 2 px (200 m) from the catalogue line, 0 dots on the catalogue (known-fault pixels are masked in scoring), values 1.0 on dots and 0.0 elsewhere inside the scored footprint, NaN outside it (nodata tag nan).

4. Why this format is safe

A previous attempt from this project was rejected with "Predicted values must be in range [0, 1]". Two mechanisms produce that error (measured by the GEMSDOE32 sibling on the official rasters): writing the feature stack's float32 nodata sentinel -3.4028234663852886e+38 through unchanged (7,113,308 cells, 3,061 inside the footprint), and NaN inside the footprint. This file has every one of the 5,167,373 template-valid pixels finite and in [0, 1], NaN only where the official sample is NaN, and the sample's own nodata tag. Both the repository validator and the template-conformance gate pass (receipts in evidence/corrections/run_card.json).

5. Honest caveats (read before spending a slot)

  • No organizer score exists for this file. The holdout number is a HOLDOUT-DTI on a simulated corrections truth — it validates the emission machinery and the controls, not the organizer's hidden labels.
  • The simulation is circular by construction for the lane arm (the simulated truth is the measured crest line); the external validation is the 1 m LiDAR calibration (crest MAD 0.29 px) and the per-record offset consistency (sign agreement up to 1.00).
  • Named non-fault process that could mimic this signal: erosional terraces and alluvial-fan edges produce the same convex slope crest without a fault; the crest can also belong to a neighbouring unmapped strand (which would still score as a new fault).
  • Uniqueness: checked against 412 unique earlier rasters: UNIQUE - no prior re-issued (literal containment flags logged and investigated below) (max Spearman 0.0429, max 3 px Jaccard 0.091).
  • Expected real-world effect: the emission captures corrections near known traces; the implied hidden truth is ~7,900 px (GEMSDOE32 estimate, user-reported family), so a corrections-only file cannot approach the live leaders by itself. Promotion to a weekly slot is a separate selector decision within the weekly cap.
