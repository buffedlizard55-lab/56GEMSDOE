This folder publishes the **validated** submission GeoTIFFs this repository produces, so that a
file can be downloaded from the site in one click, together with its receipt.

Every file here is generated by this repository's own code (`scripts/`), passes
`gates.format_report` (single band, float32, values in **[0, 1]**, EPSG:32611, matching shape and
geotransform of `sample_submission.tif`), and has an adjacent `.json` receipt carrying its
sha256, submission name and note (≤140 chars each). Whether a given file is **OK to submit** is
stated on the front page next to its download button — it is never implied.

Rules before a file is added here:

1. Generated by our own code, from data we are entitled to use (rules A.5, see the [summary](../index.html#rules)).
2. Must pass the on-disk validator (see [How to submit](../submit.html)). Receipt attached.
3. Uniqueness-screened against the sibling registry (`evidence/registry_screen_v2*.json`);
   the literal lane rule and the coverage-adjusted policy verdict are both published.
4. Name and note follow [How to submit](../submit.html#limits) (each ≤140 characters).
5. sha256 listed in the run card (`evidence/run_card_discovery_v1.json`).

*Note:* `*.tif` files are git-ignored by default; `docs/downloads/*.tif` is explicitly
re-included in `.gitignore`, so published deliverables do enter Git on purpose while raw
inputs never do.
