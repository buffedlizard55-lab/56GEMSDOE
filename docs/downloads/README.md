# Submission downloads

This folder is where a **validated** submission GeoTIFF and its receipt would be published, so that the file can be downloaded from the site.

**Currently empty, on purpose.** No file has been produced from this repository and nothing here has been scored. See the [summary](../index.html#submission-file) for why.

Rules before a file is added here:

1. It must be generated by our own code, from data we are entitled to use (rules A.5, see the [summary](../index.html#rules)).
2. It must pass `validate_submission` (see [How to submit](../submit.html)). Attach the receipt JSON.
3. It must be unique: run the registry audit and record the result in the receipt.
4. Its name and comment must follow [How to submit](../submit.html#limits).
5. Its SHA-256 must be listed in `docs/research/run-card.json`.

*Note:* `*.tif` files are git-ignored, so adding a file here requires an explicit `git add -f` and a decision (see the README). This is intentional: a large binary should not enter the Git history by accident.
